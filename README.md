# Nexa Advisory – Revenue & Profitability Analytics

## 📊 Project Overview

This project analyzes the financial and operational performance of a simulated professional services company, Nexa Advisory.

The objective is to understand project profitability, revenue performance, budget overruns, revenue leakage and project risk using data analytics.

## 🛠️ Tools Used

- SQL
- Python
- Pandas
- Power BI
- Excel

## 📈 Key Results

| Metric | Result |

| Projects Analyzed | 120 |
| Total Revenue | ₹3.30 Cr |
| Total Profit | ₹2.31 Cr |
| Average Profit Margin | 64.4% |
| Projects with Budget Overrun | 34 |
| High-Risk Projects | 1 |

## 🔍 Business Questions

- Which service lines generate the highest revenue and profit?
- Which projects are the most and least profitable?
- Which clients generate the highest revenue?
- Which projects are at higher risk?
- Where are potential revenue leakage opportunities?
- Which projects exceed their planned budget?
